# 📹 Oppo A3s ADB Debloat Tool (CCTV Setup)

Sub-folder ini berisi script ADB untuk menghapus *bloatware* pada **Oppo A3s** agar RAM lebih lega dan HP tidak cepat panas saat difungsikan sebagai kamera CCTV IP 24/7.

## 📄 Isinya Termasuk:
- `debloat-oppo-a3s.bat` : Script eksekusi otomatis via Command Prompt Windows.

## 🛠️️ Cara Menggunakan:
1. Aktifkan **Opsi Pengembang** & **Dekutu USB (USB Debugging)** di Oppo A3s.
2. Hubungkan HP ke PC/laptop menggunakan kabel data.
3. Jalankan berkas `debloat-oppo-a3s.bat` di Windows.
